Это приложение для создания и управления задачами на Python с использованием PyQt6
В программе можно добавлять задачи, писать описание, выбирать приоритет и отмечать важные задачи
Также можно удалять и редактировать задачи, фильтровать их по приоритету
Задачи сохраняются в файл tasks.json, поэтому после перезапуска программы они не пропадают
Для интерфейса использованы Qt Style Sheets, добавлены стили кнопок при наведении и отключении
В проекте реализованы удаление выбранной задачи с подтверждением, пользовательский сигнал pyqtSignal и сохранение данных в JSON
